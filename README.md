# Interactive Travel Atlas

An interactive world atlas for exploring **countries, cultures, landmarks, food, history, and notable people** through a rich visual and searchable experience.

Built with **React 19**, **Vite 8**, **TypeScript 6**, **react-simple-maps**, **Zustand**, and **world-atlas** TopoJSON data.

## Features

### 🌍 Interactive Atlas

* Explore a zoomable and interactive world map
* Filter countries by region and theme
* Select countries directly from the map

### 🗺️ Countries

* Browse countries in grid or list view
* Sort and filter the country collection
* Explore detailed country information

### 📖 Country Pages

Each country includes:

* Culture and traditions
* Landmarks
* Food
* Historical events
* Notable people
* Interesting facts

### 👤 People

Explore notable figures featured throughout the atlas, including:

* Artists
* Scientists
* Leaders

### 🏛️ Landmarks

Dedicated pages for notable landmarks with information about their history and significance.

### 🕰️ Timeline

* Explore historical events chronologically
* Discover events across different countries and periods

### ⚖️ Compare

Compare two countries side by side across key information and categories.

### ⭐ Favorites

Save countries, people, and landmarks to your browser for quick access.

### 🕑 Recently Viewed

Quickly return to countries, people, and landmarks you've recently explored.

### 🔎 Search

Instant fuzzy search across the entire atlas dataset.

## Tech Stack

* **React 19** — UI development
* **Vite 8** — Development and build tooling
* **TypeScript 6** — Type-safe development
* **react-simple-maps** — Interactive map rendering
* **Zustand** — State management
* **world-atlas** — World map TopoJSON data

## Getting Started

### Prerequisites

Make sure you have **Node.js** and **npm** installed.

### Installation

```bash
cd atlas-app
npm install
```

### Start the Development Server

```bash
npm run dev
```

Then open the local development URL provided by Vite in your browser.
