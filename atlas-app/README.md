# Interactive Travel Atlas

An interactive atlas of countries, cultures, landmarks, foods, and people.
Built with **React 19**, **Vite 8**, **TypeScript 6**, **react-simple-maps**,
**zustand**, and **world-atlas** TopoJSON data.

## Getting started

```bash
cd atlas-app
npm install
npm run dev

Features
Atlas — zoomable world map with theme and region filters.

Countries — sortable grid or list view with filters.

Country pages — culture, landmarks, foods, events, people, facts.

People — artists, scientists, and leaders from the atlas.

Landmark pages — dedicated pages for each landmark.

Timeline — every historical event in chronological order.

Compare — put two countries side by side.

Favorites — save countries, people, and landmarks to your browser.

Recently viewed — continue where you left off, from the home page.

Search — instant fuzzy search across the whole dataset.
